# LaLiga Table – ระบบแสดงตารางคะแนนและผลการแข่งขันฟุตบอล

## 1. รายละเอียดโครงงาน

LaLiga Table เป็นเว็บแอปพลิเคชันสำหรับแสดงข้อมูลการแข่งขันฟุตบอลลีก LaLiga โดยดึงข้อมูลจาก OpenLigaDB API และนำมาประมวลผลเพื่อแสดงตารางคะแนน ทีมแข่งขัน และสถิติต่าง ๆ พร้อมนำโครงสร้างข้อมูลและอัลกอริทึมมาใช้ในการจัดการข้อมูล

## 2. เทคโนโลยีที่ใช้

- **Frontend:** React และ Vite
- **Backend:** Node.js และ Express
- **API:** OpenLigaDB
- **ภาษา:** JavaScript
- **Version Control:** Git และ GitHub

## 3. ฟีเจอร์ของระบบ

1. **Standings** – แสดงตารางคะแนนของทีมในลีก LaLiga
2. **Teams & Matches** – แสดงข้อมูลทีมและการแข่งขัน
3. **Top Scorers** – แสดงรายชื่อดาวซัลโว และสามารถกดดูเพิ่มเติมได้
4. **Queue (FIFO)** – จัดการคิวข้อมูลตามลำดับเข้าก่อนออกก่อน
5. **Stack (LIFO)** – จัดเก็บประวัติการทำงานตามลำดับเข้าทีหลังออกก่อน
6. **Undo** – ย้อนกลับการทำงานก่อนหน้า
7. **Sorting Algorithms** – ใช้อัลกอริทึม Selection Sort, Insertion Sort และ Bubble Sort ในการเรียงลำดับข้อมูล
8. **Statistics** – แสดงข้อมูลสถิติของการแข่งขัน

## 5. วิธีติดตั้งและเปิดใช้งาน

### 5.1 ติดตั้ง Backend

เปิด Terminal แล้วเข้าโฟลเดอร์ backend

```bash
cd backend
npm install
```

เริ่มต้นเซิร์ฟเวอร์ด้วยคำสั่ง

```bash
npm run dev
```

### 5.2 ติดตั้ง Frontend

เปิด Terminal อีกหน้าต่าง แล้วเข้าโฟลเดอร์ frontend

```bash
cd frontend
npm install
```

เริ่มต้นเว็บไซต์ด้วยคำสั่ง

```bash
npm run dev
```

จากนั้นเปิดเว็บไซต์ตาม URL ที่ Vite แสดงใน Terminal โดยปกติคือ

```text
http://localhost:5173/
```

## 6. การทำงานของ Backend และ API

Backend พัฒนาด้วย Express เพื่อเป็นตัวกลางในการจัดการข้อมูลระหว่าง Frontend และ OpenLigaDB API รวมถึงประมวลผลข้อมูลและจัดการโครงสร้างข้อมูลของระบบ

ตัวอย่าง API Routes ที่ใช้ในโปรเจกต์

| Method | API Route | หน้าที่ |
|---|---|---|
| GET | /teams | ดึงข้อมูลทีม |
| GET | /scorers | ดึงข้อมูลดาวซัลโว |
| GET | /teamqueue | ดูข้อมูลใน Queue |
| POST | /teamqueue/process | ประมวลผลข้อมูลใน Queue |
| GET | /history | ดูประวัติการทำงาน |
| POST | /undo | ย้อนกลับการทำงาน |

## 7. โครงสร้างข้อมูลและอัลกอริทึม (DSA)

### 7.1 Queue (FIFO)

ใช้จัดการข้อมูลตามลำดับเข้าก่อนออกก่อน เหมาะสำหรับการจัดการรายการที่รอประมวลผล

### 7.2 Stack (LIFO)

ใช้จัดเก็บประวัติการทำงาน โดยรายการที่เพิ่มเข้ามาล่าสุดจะถูกนำออกก่อน และนำไปใช้ร่วมกับระบบ Undo

### 7.3 Sorting Algorithms

นำอัลกอริทึมสำหรับเรียงลำดับข้อมูลมาใช้ ได้แก่

- Selection Sort
- Insertion Sort
- Bubble Sort

อัลกอริทึมทั้งสามมีเวลาในการทำงานกรณีทั่วไปและกรณีแย่ที่สุดอยู่ในระดับ O(n²) โดยนำมาใช้กับข้อมูลจริงของระบบ เพื่อช่วยจัดเรียงข้อมูลให้แสดงผลได้ตามต้องการ

## 9. ข้อเสนอแนะจากงานครั้งที่ 1 และการปรับปรุง (Before / After)

| ข้อเสนอแนะจากงานครั้งที่ 1 | สิ่งที่ปรับปรุงในงานปัจจุบัน | หลักฐาน Before / After |
|---|---|---|
| เพิ่มความสะดวกในการดูรายชื่อดาวซัลโว | เพิ่มฟังก์ชันดูเพิ่มเติม เพื่อให้ผู้ใช้สามารถดูรายชื่อดาวซัลโวได้มากขึ้น | แนบภาพหน้าเดิมและหน้าปัจจุบัน |
